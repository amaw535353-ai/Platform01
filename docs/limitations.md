# Limitations and residual risk
This is not production-ready, standards-compliant, or a security certification. Tested evidence covers the deterministic in-process slice only. Docker is unavailable in the authoring environment, so Compose startup, image digests, PostgreSQL RLS, OPA, and Kubernetes were not executed. Keycloak, JWT signature/JWKS rotation, browser login/state/nonce/session, standards-based token exchange, official MCP SDK Streamable HTTP, live double-PEP OPA calls, LangGraph, pgvector ranking, Presidio, rate/concurrency/circuit breakers, OTEL viewer, DNS rebinding defenses, backup/restore, revocation, and workload identity are documented/structural gaps. Image digests and GitHub Action SHAs require verification before operational use. Persistent memory is absent/off. No real external effects exist. Finite synthetic tests do not establish universal security.
